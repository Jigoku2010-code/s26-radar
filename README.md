# S26 Radar

Deal tracker for the Samsung Galaxy S26 Ultra (512GB and 1TB) in the Netherlands, Italy, Germany, Belgium and Luxembourg.

- `index.html` is the app page. It loads `deals.json` every time it opens.
- `deals.json` holds the prices, promotions, alerts and price history. A scheduled Claude task updates it about every 2 hours.

Open it at https://jigoku2010-code.github.io/s26-radar/ once GitHub Pages is on.
